O CETAM está com um projeto de jogo plataforma 2D side-scroller em desenvolvimento e está em fase de prototipagem, por isto está apresentando uma série de problemas e mecânicas que devem ser adicionadas.

1. Abaixo está a lista de problemas presentes no jogo:
- A movimentação do jogador está apresentando problemas, corrija para que funcione com as setas para os lados. (0.5 pontos)
- Há uma plataforma no cenário, mas esqueceram de adicionar seu colisor. (0.5 pontos)
- A gravidade aplicada ao jogador está muito level, faça com que fique mais "pesada": a gravidade deve ser 8 vezes mais forte que o padrão. (0.5 pontos)
- Corrija o problema ao pressionar o botão de créditos no menu principal. (0.5 pontos)
- Corrija o contador de maçãs na UI do jogo, este não está atualizando. (1.0 pontos)
- Atualize a tela de créditos, há um texto mostrando a descrição dos créditos, nesse texto deve ser adicionados o nome da(s) pessoa(s) que estão realizando esse ajuste (dupla ou programador que fizeram a prova) esse texto deve ficar centralizado verticalmente e horizontalmente. (1.0 pontos)
- O pulo do jogador está muito fraco, corrija para que seja o suficiente para "pular" a própria altura do jogador e não pode ser maior do que 5 vezes a sua própria altura, também corrija o som de pulo do jogador. (1.5 pontos)

<br/>

2. Abaixo está a lista de funcionalidades que você deve adicionar ao jogo:
- Adicione uma música ao menu principal e menu de créditos. (0.5 pontos)
- Na tela de créditos adicione botão para retornar ao menu principal e implemente sua funcionalidade para retornar para a cena do menu principal do jogo. (1.0 pontos)
- Adicione um efeito sonoro para a coleta de maçãs. (1.5 pontos)
